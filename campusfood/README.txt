Campus Food HTML UI Refresh

What is inside:
- Refreshed HTML files for all uploaded Campus Food pages.
- A matching style.css that includes the earlier beautiful UI refresh plus extra helper classes used by these pages.

How to use:
1. Copy these files into your campusfood folder.
2. Replace the old HTML files and style.css.
3. Do not replace your js folder.
4. Run the app and test login, dashboards, menu, orders, payments, analytics, and modals.

Important:
The refreshed HTML keeps the existing IDs, onclick handlers, scripts, and file paths so your current JavaScript should still find the elements it needs.
